# Linux System Monitoring Dashboard

A real-time Linux system monitoring dashboard built on Fedora Linux using Python and Flask.  
This project provides live monitoring of system resources such as CPU, memory, disk usage, network statistics, and running processes through a clean web interface.

---

## Features

- Real-time CPU monitoring
- Memory usage tracking
- Disk usage monitoring
- Network upload/download statistics
- Linux system information display
- Top running process monitoring
- REST API endpoints for system stats
- Lightweight web dashboard
- Fedora/Linux compatible

---

## Tech Stack

- Python
- Flask
- psutil
- HTML
- CSS
- JavaScript
- Fedora Linux
